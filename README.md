# College-to-Home Route Planner

## Project Overview
The College-to-Home Route Planner is a web application designed to help users plan routes between their college and home.

## Technologies Used
- Frontend: React
- Backend: Python Flask
- Frontend Deployment: Vercel

## Project Structure
- `aniket07-main/` – Frontend application
- `backend/` – Backend application

## Live Demo
https://college-home-route-planner-46.vercel.app/

## Source Code
The source code for the frontend and backend is available in this repository.

## How to Run
Run the frontend and backend separately using their respective project instructions and dependencies.
